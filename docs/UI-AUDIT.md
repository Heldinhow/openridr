# UI-AUDIT — OpenRidr MVP (Rider-like)

Data: 29/10/2026. Escopo: jornada visual do MVP F1–F9 no Chrome real (headed), contra o host HTTP de desenvolvimento e o Vite em modo E2E, com a fixture `OrderDesk` e ferramentas reais. Documento em PT-BR; UI em inglês.

## Ambiente e método

- Chrome 155 (canal `chrome`), `headless:false`, `slowMo:300`, janela 1600×1000; capturas adicionais em 1440×900 e 1100×700.
- Host `openridr-host-http` em `127.0.0.1:4317` (`OPENRIDR_ENABLE_PROBE=1`, `OPENRIDR_HOME` isolado); Vite E2E em `1420`; `PATH`/`DOTNET_ROOT` com o SDK 8.0.408 de `~/.dotnet`.
- Fixture copiada para um diretório temporário com espaço no caminho (`.../openridr-ui-audit/orderdesk`) e uma segunda cópia inicializada como repositório git descartável para os fluxos de Git. Nada foi alterado em `fixtures/OrderDesk` nem no repositório do app.
- Cada tela foi capturada em `docs/evidence/ui-audit/`; os textos visíveis de cada captura estão em `.scratch/ui-audit/text/` (fora do commit). As medições de largura/truncamento citadas vêm do DOM no momento da captura.
- Limitações: a janela Tauri nativa não foi dirigida (mesmo seam do AC-32); não houve leitor de tela nem auditoria WCAG formal; Windows/macOS Intel não foram executados. Não foram exercitados: push com remote real, pull com upstream, update NuGet real, CPM, MTP, debug de teste, cancelamento de teste, conflito de disco lado a lado, troca de perfil IntelliJ e temas (só existe o escuro). O `dotnet` do PTY não herdou o SDK 8.0.408 pinado (ver M5); isso é ambiental e está declarado.

## Resumo

**30 desvios: 8 altos, 13 médios, 9 baixos.**

Os cinco mais graves, na ordem em que atrapalham o trabalho diário:

1. **A1 — saída do Run não aparece.** Depois de rodar, o painel Build mostra metadados do build e o selo `Run exited · exit 0`, mas o stdout fica abaixo da dobra; não existe tool window Run. ([25-run-output](evidence/ui-audit/25-run-output.png))
2. **A2 — testes e debug escondem o conteúdo principal.** Árvore/resultados de testes e frames/locals do DAP ficam abaixo da dobra no painel inferior de ~250 px, atrás de metadados de descoberta/execução. ([61-tests-discovered](evidence/ui-audit/61-tests-discovered.png), [62-tests-results](evidence/ui-audit/62-tests-results.png), [81-debug-paused](evidence/ui-audit/81-debug-paused.png))
3. **A3 — diff do Git ilegível.** O diff abre dentro do painel Commit de 280 px, com linhas cortadas e sem scroll horizontal; não dá para revisar o que será commitado. ([51-git-diff](evidence/ui-audit/51-git-diff.png))
4. **A4 — desabilitado parece habilitado.** `button.primary`/`.danger` sobrepõem o estilo `:disabled`; o botão de trust, o de instalar o adapter, os selects read-only do run config e itens de menu desabilitados continuam com a cor de ação. ([03-toolchain-restricted](evidence/ui-audit/03-toolchain-restricted.png), [22a-install-plan](evidence/ui-audit/22a-install-plan.png), [38-run-config-default](evidence/ui-audit/38-run-config-default.png), [71-editor-context-menu](evidence/ui-audit/71-editor-context-menu.png))
5. **A5 — plano de instalação esconde os campos materiais.** A faixa de 24 vh mostra só `Tool`/`Source`; comando, destino, staging, permissões, integridade e limites ficam abaixo da dobra, enquanto `Confirm and install` já está visível. O mesmo vale para o plano do netcoredbg. ([22a-install-plan](evidence/ui-audit/22a-install-plan.png), [78-debug-plan](evidence/ui-audit/78-debug-plan.png))

## O que não é desvio

- **Sem menu bar `File/Edit/View/...`**: o wireframe 02 mostra uma, mas a SPEC-MVP-RIDER F1 e a decisão F1 substituem por uma única barra de 44 px com projeto/branch/config/Run/Debug/busca/Settings e o registro de ações. Não contar como falta.
- **Aba Symbols sem tipos**: a decisão F3 separa tipos (Classes) de membros (Symbols) pelo `kind`; buscar `Order` em Symbols devolver "No results" é o contrato, não falha. Só a ausência de uma dica para a aba Classes entra como L4.
- **Ausência de gutter Run no `Program.cs` top-level**: a F7 permite não inventar posição quando o entry point não é determinável; o fixture usa top-level statements (`<Main>$`), então isso é uma lacuna de prova, não necessariamente um bug. Fica fora da contagem; a cobertura de gutter test/run em arquivo com `Main` explícito não foi exercitada.
- **Tema claro ausente**: é decisão explícita (F8 #68), com nota na UI. Só o formato do select entra como L8.
- **Backdrop/contraste dos modais**: verificado por amostragem de pixel (o fundo cai de ~189 para ~85 em RGB); não é desvio.
- **Windows/macOS Intel**: não executados; nada aqui os aprova.
