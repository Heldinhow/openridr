# Triage labels

As skills falam em cinco papéis canônicos de triagem. Este arquivo mapeia cada papel para a string de label usada no issue tracker deste repo.

| Papel (skills) | Label neste repo | Significado |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | O mantenedor precisa avaliar |
| `needs-info` | `needs-info` | Esperando informação de quem reportou |
| `ready-for-agent` | `ready-for-agent` | Especificado, pronto para um agente sem supervisão |
| `ready-for-human` | `ready-for-human` | Precisa de implementação humana |
| `wontfix` | `wontfix` | Não será feito |

Categoria (exatamente uma por issue triada), já existentes no repo: `bug`, `enhancement`.

Quando uma skill citar um papel (ex.: "aplique o label de pronta para agente"), use a string da coluna "Label neste repo".

Se um dia o tracker passar a usar outros nomes (ex.: `bug:triage` em vez de `needs-triage`), edite só a coluna da direita; o resto continua valendo.
